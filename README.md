# NUMMAZA

Бюджет-ассистент для Казахстана. Главная цифра — «Сегодня можно потратить». Приложение разбирает PDF-выписку Kaspi Gold (а также Halyk, Freedom и CSV), раскладывает траты по конвертам, следит за целями и отвечает на вопросы через ассистента Numa — на русском, казахском и английском.

Все данные хранятся на устройстве (localStorage). Сервер не нужен, выписка никуда не отправляется.

## Что внутри

| Папка | Что это |
|---|---|
| `app/` | Веб-приложение: HTML + CSS + JavaScript без сборщика |
| `app/js/core.js` | Категории, хранилище, даты, расчёт «Сегодня можно», конверты, цели, советы |
| `app/js/parser.js` | Разбор PDF/CSV-выписок, распознавание магазинов и своих переводов |
| `app/js/numa.js` | Ассистент Numa: понимает вопрос (RU/ҚАЗ/EN) и считает ответ по данным |
| `app/js/i18n.js` | Все тексты интерфейса на трёх языках |
| `app/js/app.js` | Экраны, навигация, действия, отмена через тост |
| `android/` | Android-оболочка (WebView) и скрипт сборки APK без Android Studio |
| `tests/` | Сквозной тест в браузере (60 проверок) и генератор тестовой выписки |
| `scripts/build_web.py` | Сборка веб-версии в один HTML-файл |

## Функции

- Регистрация и вход (пароль хранится как SHA-256 с солью, 5 ошибок → блокировка на 15 минут), сброс данных, удаление аккаунта с подтверждением словом.
- Онбординг в 4 шага: язык и тема, доход и день зарплаты, первая цель, выписка или пример данных.
- «Сегодня можно потратить» с раскрываемой формулой; перерасход распределяется на оставшиеся дни.
- Календарь трат (уровни цвета считаются от дневного лимита), ближайшие обязательные платежи, советы с суммой экономии.
- Импорт выписки: PDF Kaspi/Halyk/Freedom и CSV, пропуск дубликатов, переводы между своими счетами не считаются тратами, сомнительные операции помечаются «проверьте».
- Исправление категории с правилом «всегда так для этого магазина».
- Конверты: лимиты по категориям, автопредложение лимитов, запрет лимитов выше дохода, перенос денег между конвертами.
- Ассистент Numa: бюджет, переплаты, лимит на сегодня, траты по категории, подписки, цели, депозиты (с оговоркой), дорогие дни недели; у каждого ответа есть «на чём основан ответ».
- Цели: статус «опережаете / по плану / отстаёте», отметки 25/50/75%, экран-поздравление на 100%.
- Итоги месяца в формате сторис, «Поделиться» со скрытыми суммами.
- Добавление операции вручную с цифровой клавиатурой, живой подсказкой по конверту и черновиком на 10 минут.
- Отмена через тост вместо «Вы уверены?», работа без интернета, дневная/ночная тема, три языка, версия для компьютера с боковым меню.

## Запуск

Откройте `app/index.html` в браузере — больше ничего не нужно.

## Тесты

```bash
python3 tests/make_sample_pdf.py /tmp/kaspi_sample.pdf 2026-11-04
```

```bash
printf 'Дата;Сумма;Описание\n01.11.2026;-2 500,00;Starbucks Dostyk\n02.11.2026;-1 200;Yandex.Go\n03.11.2026;+5 000;Возврат Wildberries\n' > /tmp/sample.csv
```

```bash
NODE_PATH=$(npm root -g) node tests/e2e.mjs app/index.html /tmp/nz-shots
```

Тестовая выписка в `tests/make_sample_pdf.py` — самодельная, в формате Kaspi Gold. Перед релизом разбор нужно проверить на нескольких настоящих выписках.

## Веб-версия одним файлом

```bash
python3 scripts/build_web.py dist/nummaza-web.html
```

Файл `dist/nummaza-web.html` можно выложить на любой статический хостинг (GitHub Pages, Netlify, Vercel).

## APK для Android

```bash
android/build.sh
```

Нужны JDK 17+, python3, curl и zip. Скрипт сам скачивает с Maven Central aapt2 (из apktool-lib), dx и apksig, компилирует WebView-оболочку и подписывает APK схемой v2. Результат — `dist/NUMMAZA.apk` (Android 8.0+, targetSdk 34).

При первой сборке создаётся ключ `android/nummaza-release.p12` с паролем по умолчанию. Для публикации в Google Play создайте свой ключ и передайте его через переменные `KEYSTORE` и `KEYSTORE_PASS`; храните ключ в секрете и не добавляйте в git.
